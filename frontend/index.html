Core DSA Algorithmic Engine Visualizers

Interactive algorithmic demonstrators for Singly Linked List, BST, Sliding Window, and Hash Map.

Singly Linked List — Financial Transaction Ledger

Complexity: O(1) Prepend

Every financial transaction is encapsulated in a TransactionNode with a pointer (next) pointing to the prior transaction. Inserting at the head executes in constant $O(1)$ time without array-shifting penalties.

Binary Search Tree (BST) — Account Hierarchy & Search

Complexity: O(log N) Search / O(N) In-Order

Maintains an ordered binary tree sorted by account_number. Enables logarithmic search and guaranteed sorted reporting via In-Order traversal (Left → Root → Right).

Sliding Window Algorithmic Engine

Complexity: O(1) Amortized Maintenance

The Sliding Window maintains a double-ended queue of length $K$. When a $(K+1)$-th transaction enters, the oldest transaction is evicted in $O(1)$ time, and the rolling sum is updated.

Hash Map Indexing — Instant O(1) Account Retrieval

Complexity: O(1) Primary Key Lookup

Primary indexing structure storing key-value pairs { account_number: BankAccount } for instantaneous lookup during financial transactions.
